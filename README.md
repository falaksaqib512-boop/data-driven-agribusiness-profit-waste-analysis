Data-Driven Agribusiness: Profit & Supply-Chain Waste Analysis

Project Overview

This project uses SQL and Python to analyze multi-farm agribusiness data and identify patterns in farm profitability and supply-chain waste.

The analysis focuses on comparing crop-level profitability across farms and examining the percentage of agricultural products lost during transportation.

Key Findings

- Timber generated the highest reported profit for GreenValley Farms, exceeding £3,000.
- Highland Agro experienced approximately 8% supply-chain waste for Apples.
- GreenValley Farms recorded zero reported waste for Cherries while remaining profitable.
- Profitability and supply-chain waste varied across farms and crop types.

Tools & Technologies

Analysis

The project transformed multi-farm agribusiness data into meaningful business and agricultural insights.

Profit Analysis

The analysis compared net profit across different crop types and farms to identify the most profitable agricultural products.

Supply-Chain Waste Analysis

The project examined the percentage of crop waste occurring during transportation and compared waste patterns between farms.
